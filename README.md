# LLM-Based Human Behaviour-Aware Decision-Making for Autonomous Vehicles

Junior Project, College of Computing and Informatics, University of Sharjah.
Supervisors: Dr Ibrahim, Dr Bouziane.

## Overview
This project investigates whether prompt-engineered large language models can
generate diverse human–AV driving scenarios and support context-aware, high-level
AV recommendations. It is an LLM-based decision-support prototype; it does not
control a vehicle and does not involve model training or fine-tuning.

## Architecture
Synthetic scenario generation (Gemini) -> structured scenario dataset
(32 features) -> decision prompt -> local Llama -> high-level AV
recommendation -> web/chatbot prototype.
